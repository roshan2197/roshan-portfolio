#### Md Roshan — Portfolio

This is a lightweight static portfolio built from Roshan's resume. The phone number is intentionally omitted. Files included:

- index.html — main static page
- styles.css — styling for the page

How to use
1. Add these files to your repository root (or a gh-pages branch).
2. Commit and push:
   - git add index.html styles.css README.md
   - git commit -m "Add portfolio site (no phone number included)"
   - git push origin gh-pages

3. Publish using GitHub Pages (if not already enabled):
   - In the repository Settings -> Pages, set the source to the branch gh-pages and folder root (/).
   - Visit https://roshan2197.github.io/roshan-portfolio/ after the site builds.
